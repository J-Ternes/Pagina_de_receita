# Página de Receita

Projeto de uma página estática de receita desenvolvido com **HTML5** e **CSS3**, com foco em estruturação semântica, organização visual e estilização de uma interface agradável.

A página apresenta a receita de **Cupcake de café com chantilly**, exibindo descrição, tempo de preparo, rendimento, dificuldade, ingredientes e modo de preparo em um layout limpo e elegante.

## Preview do projeto

Repositório: [Pagina_de_receita](https://github.com/J-Ternes/Pagina_de_receita)

## Tecnologias utilizadas

- **HTML5**
- **CSS3**

## Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar:

- Estruturação de páginas com HTML semântico
- Estilização com CSS
- Organização visual de conteúdo
- Uso de imagem de fundo
- Aplicação de tipografia e espaçamento
- Construção de uma interface estática bonita e funcional
